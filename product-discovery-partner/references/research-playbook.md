# 外部研究 Playbook

用户的自述不足以支撑所有判断。竞品、替代方案、定价、渠道、监管和技术能力，很多时候需要外部输入。外部研究的目标不是写行业报告，而是回答会改变决策的问题。

## 1. 什么时候研究

- 用户说“没有竞品”“我们是第一个”，但不确定。
- 需要判断替代方案、定价、渠道或市场饱和度。
- 产品涉及监管、牌照、数据、内容审核或平台规则。
- 需要评估 AI 模型、API、成本或延迟是否可行。
- 用户对市场的判断只有印象，没有来源。
- 决策门需要外部证据才能判断 CONTINUE / PIVOT / STOP。

不要在早期做大规模市场研究。先问：哪个外部事实最可能改变当前决策？

## 2. 研究问题

### 竞品与替代

- 直接竞品有哪些？它们服务谁、解决什么问题？
- 间接替代方案是什么：Excel、人工、外包、内部系统、群聊？
- 用户为什么选择现状而不是竞品？
- 竞品的定价、包装、获客渠道和留存机制是什么？
- 有没有产品已经覆盖了 70% 的需求？如果有，差异化在哪里？

### 市场与用户

- 目标用户集中在哪些渠道、社区、平台或行业？
- 市场是增长、稳定还是萎缩？
- 有没有最近的政策、技术或平台变化创造机会窗口？
- 用户现在用什么关键词搜索解决方案？

### 监管与合规

- 是否需要牌照、备案、审批或行业许可？
- 是否涉及个人信息、支付、医疗、金融、教育、儿童或内容？
- 平台规则是否限制获客、自动化或数据使用？
- 数据是否可以跨境传输？

### 技术

- 关键能力是否已有成熟 API 或开源方案？
- 成本、延迟、准确率和稳定性是否满足产品要求？
- 是否需要自建模型、微调或私有化部署？
- 供应商锁定和迁移成本如何？

## 3. 来源等级

| 等级 | 来源 | 能支持什么 |
|---|---|---|
| A | 官方文档、价格页、监管原文、公开财报、产品实际界面 | 事实性判断 |
| B | 独立媒体、行业报告、学术研究、可信数据库 | 趋势和背景 |
| C | 厂商博客、销售材料、案例宣传 | 厂商声称什么，不等于效果 |
| D | 助手记忆、未注明来源的二手总结 | 不能作为证据 |

规则：

- 每条外部证据记录来源名称、URL、访问日期和原文摘要。
- 区分“事实”和“厂商声称”。
- 不要用一个来源证明整个市场。
- 价格、融资、法规和模型能力会变化，必须注明日期。
- 如果无法核实，标为 `[猜测 G-xx]` 或 `[待确认 Q-xx]`。

## 4. 联网研究协议

如果有 web search 或 fetch 能力：

1. 先写 3–5 个具体研究问题。
2. 每个问题做 1–2 次目标搜索，不要漫无目的浏览。
3. 优先打开一手来源。
4. 记录 URL、日期和关键引文。
5. 把结果压缩成「结论 + 证据 + 对决策的影响」。
6. 把外部证据写入证据账本，使用 `[R-01]` 编号。

输出格式：

```markdown
## 研究结论
- 结论 1：[一句话]
  - 来源：[名称](URL)，访问日期：YYYY-MM-DD
  - 置信度：高/中/低
  - 对决策的影响：...

## 仍然不确定
- ...
```

不要输出长度超过结论的“研究过程”。用户要的是判断，不是搜索日志。

## 5. 没有联网能力时

明确说明限制：

```text
我现在无法联网核实竞品和定价。我可以给你一份精确的搜索清单和待填表；你查完把结果贴回来，我再更新判断。
```

提供：

- 精确搜索词。
- 需要查看的页面类型（官网定价页、应用商店、监管原文、招聘信息等）。
- 一张待填表：来源、URL、日期、关键事实、对决策的影响。
- 不要编造任何 URL、价格、融资或法规条款。

## 6. 竞品扫描模板

```markdown
# 竞品与替代方案扫描

## 目标用户
...

## 直接竞品
| 产品 | 目标用户 | 核心价值 | 定价 | 渠道 | 优势 | 弱点 | 来源 |
|---|---|---|---|---|---|---|---|

## 间接替代
| 替代方式 | 用户为什么用它 | 成本 | 为什么可能不够好 |
|---|---|---|---|

## 用户当前工作流
...

## 差异化假设
- 我们相信 ...
- 需要验证 ...

## 对决策的影响
- CONTINUE / NARROW / PIVOT / PAUSE / STOP
```

```markdown

...

- [ ] ...

- 成本：

- 收集什么数据：
- 是否需要同意：
- 是否允许跨境：
- 保存期限：

## 内容与平台规则
- 平台：
- 限制：
- 审核要求：

- 可能无法做：
```

涉及法律、医疗、金融、儿童等高风险领域时，明确说明这不是法律意见，建议咨询专业人士并核实最新官方要求。

## 8. 研究剧场

避免以下“研究剧场”：

- 收集大量链接，但没有改变任何判断。
- 只找支持当前方向的证据。
- 用市场规模报告证明需求，而不是用户行为。
- 把竞品功能列表当成用户需求。
- 用“没有竞品”作为机会证明，而不检查替代方案。
- 引用无法打开的 URL 或过时数据。

每一条研究都应该回答：它改变了哪个判断？如果没有，就不要写进产物。

## 9. 写入证据账本

研究结束后：

- 每条关键事实建立一个 `[R-xx]` 条目。
- 标注来源等级、日期、置信度和适用范围。
- 把与用户自述冲突的地方标出来。
- 更新相关假设的置信度。
- 如果研究推翻了原方向，重新运行决策门。
